# Свинтус

Издание: классическая колода на 112 карт.
64 цифровые (цвета красный / жёлтый / зелёный / синий, номиналы 0–7, по две каждого).
48 специальных, по две каждого цвета:

- Захрапин — следующий пропускает ход.
- Перехрюк — меняет направление.
- Хапеж — следующий берёт 3 карты и пропускает ход.
- Молчагрив — все молчат, пока ход не вернётся к выложившему; нарушитель берёт 2.
- Хлопкопыт — все хлопают по столу; последний берёт 2.
- Полисвин — на любой цвет, назовите новый цвет.

1. Раздайте по 8 карт. Ходите в цвет или в номинал (для спецкарт — в цвет или в ту же спецкарту).
2. Дубликаты позволяют перехват: та же карта вне очереди.
3. Кто остался с одной картой и не сказал «свинтус» — штрафные карты.
4. Кто сбросил всю руку — победил раздачу.
