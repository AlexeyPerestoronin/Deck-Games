# Phase 10

Колода: 108 карт. Четыре цвета, числа 1–12 (по две каждого цвета), 8 джокеров, 4 пропуска хода.

Десять фаз (по порядку, по одной за сдачу):
1. 2 сета по 3.  2. Сет 3 + улица 4.  3. Сет 4 + улица 4.
4. Улица 7.  5. Улица 8.  6. Улица 9.
7. 2 сета по 4.  8. 7 карт одного цвета.  9. Сет 5 + сет 2.  10. Сет 5 + сет 3.

1. Раздайте по 10 карт. Цель сдачи — выложить свою текущую фазу, затем сбросить остальные.
2. Сет — карты одного номинала. Улица — consecutive числа (цвет не обязан совпадать, кроме фазы 8).
3. Джокер заменяет любую карту. «Пропуск хода» сбрасывается на другого игрока.
4. После фазы можно пристраивать карты к уже лежащим комбинациям.
5. Кто первый закрыл руку, заканчивает сдачу. Очки на руках — штраф. Кто раньше прошёл фазу 10 с меньшим штрафом — победил.
