# Уно

Колода: 108 карт. Четыре цвета — красный, жёлтый, зелёный, синий.

На цвет: по одной «0», по две «1»–«9», по две «пропуск», «реверс» и «+2».
Отдельно: 4 дикие карты цвета и 4 дикие «+4».

1. Раздайте по 7 карт. Верхняя карта колоды открывает сброс.
2. Ходите картой того же цвета или того же номинала (знака).
3. «Пропуск» — следующий без хода. «Реверс» — меняет направление. «+2» — следующий берёт две и пропускает.
4. Дикая карта — назовите цвет. Дикая «+4» — цвет и четыре карты следующему.
5. Перед последней картой скажите «Уно». Кто сбросил все карты — победил.
