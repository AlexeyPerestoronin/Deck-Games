# The Mind

Колода: 100 карт, номера строго 1–100. На лице — только число.

1. Команда играет молча: никаких слов, жестов-подсказок, условных сигналов.
2. На уровень n каждому дают n карт. Нужно выложить все карты в одну стопку по возрастанию.
3. Игрок кладёт карту, когда считает, что на столе уже нет меньших у других.
4. Ошибка (на столе оказалась меньшая карта в руке) — потеря жизни, мелкие карты сбрасывают.
5. Жизни и метания звёзд — по числу игроков и уровню. Пройти согласованные уровни — победа.
