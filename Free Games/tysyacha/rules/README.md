# Тысяча (1000)

Колода: 24 карты (9, 10, валет, дама, король, туз) — классика на троих. На четверых обычно берут 32 карты.

Очки на картах: туз 11, десятка 10, король 4, дама 3, валет 2, девятка 0.

1. Сдают по 7 карт (троим), 3 карты в прикуп.
2. Торговля за прикуп. Победитель берёт прикуп и заказывает очки.
3. Ходят по масти. Козырь назначается марьяжем: король + дама одной масти на руке, объявленные при ходе.
   Марьяжи: черви 100, бубны 80, трефы 60, пики 40.
4. Считают взятки плюс марьяжи. Цель партии — первым набрать 1000 очков.
