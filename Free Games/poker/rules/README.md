# Покер (техасский холдем)

Колода: 52 карты. Комбинация — лучшие 5 карт из двух карманных и пяти общих.

Старшинство комбинаций (по возрастанию силы): старшая карта, пара, две пары, сет, стрит, флеш, фулл-хаус, каре, стрит-флеш, роял-флеш.

1. Блайнды. Каждому раздают 2 закрытые карты.
2. Префлоп — круг ставок.
3. Флоп — три общие карты, круг ставок.
4. Тёрн — четвёртая общая карта, круг ставок.
5. Ривер — пятая общая карта, круг ставок.
6. Вскрытые руки сравниваются. Можно выиграть и без вскрытия — если все сбросились.
