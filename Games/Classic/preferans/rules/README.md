# Преферанс

Колода: 32 карты (от семёрок до тузов). Классика — на трёх игроков (четвёртый может сдавать).

1. Сдают по 10 карт, 2 карты в прикуп.
2. Идёт торговля за заказ: кто возьмёт игру, тот играет против двоих вистующих.
3. Играющий берёт прикуп, сбрасывает две карты и объявляет козырь (или без козыря) и число взяток.
4. Старшинство в масти: 7 < 8 < 9 < 10 < валет < дама < король < туз. Козырь бьёт некозырную масть.
5. Нужно выполнить заказ. Недобор и перебор пишутся на пулю и гору по принятой в компании конвенции.
