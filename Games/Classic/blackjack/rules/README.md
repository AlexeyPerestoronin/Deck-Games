# Блэкджек (Двадцать одно)

Колода: 52 карты. На картах указаны очки: туз — 1 или 11, картинки и десятка — 10.

1. Игрок и дающий получают по две карты. Одна карта дающего обычно открыта.
2. Цель — набрать сумму **ближе к 21, чем у дающего**, не превысив 21.
3. Можно взять ещё карту (hit) или остановиться (stand).
4. Ровно 21 из двух карт (туз + 10/картинка) — блэкджек.
5. Перебор (больше 21) — проигрыш. Дающий обычно берёт карты до 17.
