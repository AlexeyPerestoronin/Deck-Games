# Deck Games
Репозиторий содержащий шаблоны генерации для карточных колод настольных игр при помощи [Game-Deck-Generator](https://github.com/AlexeyPerestoronin/Game-deck-generator).

# Как устроена игра:

Каждая игра - это:
1. специальная папка в корне которой находится файл `games.json5`, определяющий ключевые параметры игры:
   - `game-name` - обязательный параметр, задающий имя игры;
   - `folders` - обязательный параметр, задающий относительные имена целевых папок для поиска файлов игры;
   - `output` - обязательный параметр, задающий относительные имена целевых папок для файлов auto-генерируемых файлов игры;
   - `print` - обязательный параметр, задающий правила для печати pdf;
2. множество папок игровых колод, определяющихся как подпапки в папке по параметру `folders/decks` в `games.json5`, каждая из которых содержит свой собственный файл `data.json5`, определяющий ключевые параметры колоды:
   - `name` - обязательный параметр, задающий имя для колоды в рамках игры (имена должны быть уникальными в рамках игры);
   - `view` - обязательный параметр, определяющий какие файлы использовать для внешнего вида лицевой и оборотной стороны карт данной колоды (виды хранятся в папке по параметру `folders/views` в `games.json5`);
   - `decks` - обязательный параметр, определяющий переменные одинаковые для всех карт колоды;
   - `cards` - обязательный параметр, задающий количество карт, равное количеству элементов в массиве, где каждый элемент массива определяет переменные уникальные для конкретной карты;
   - `vars` - не обязательный параметр, внутри которого локальные определяются переменные, т.е. такие которые могут быть использованы только внутри данной колоды:
     - локальные переменные определяются по правилу {vars.<ключ-1>.<ключ-2>...<ключ-N>} → при генерации будет подставлено значение найденное по ключу;
     - глобальные переменные определяются по правилу {<file-name>:<ключ-1>.<ключ-2>...<ключ-N>} → при генерации будет подставлено значение найденное по ключу в соответствующем json5-файле с переменными, который должен находится в папке по параметру `folders/vars` в `games.json5`.
