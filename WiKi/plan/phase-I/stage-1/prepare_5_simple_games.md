# Задача: «create new 5 simple games»

Необходим создать 5 новых карточных игр, состоящих из одной колоды, в папке `Free Games`.

Список игр, которые необходимо создать с небольшим описанием для ясности, какая игра имеется ввиду:
1. Дурак:
   ```
   Самая популярная народная игра в странах СНГ, где игроки избавляются от карт, отбивая нападения соперников с помощью козырей.
   ```
2. Блэкджек (Двадцать одно):
   ```
   Классическая азартная игра, цель которой — набрать комбинацию карт, максимально близкую к 21 очку, но не превышающую это число.
   ```
3. Покер (например, Техасский Холдем):
   ```
   Всемирно известная интеллектуальная игра, в которой игроки собирают комбинации и соревнуются в умении блефовать и просчитывать ставки.
   ```
4. Преферанс:
   ```
   Сложная и глубокая стратегическая игра на взятки, популярная среди любителей математического расчета и логики.
   ```
5. Тысяча (1000):
   ```
   Увлекательная игра на взятки для трех или четырех человек, где главная цель — первым набрать 1000 очков, используя комбинации из дамы и короля одной масти (марьяжи).
   ```

Требования к созданию:
1. Базовые правила создания игры написаны в `README.md` в главе `# Как устроена игра:`.
2. Если игровая колода требует картинки на лицевую или оборотную стороны колоды, таковые картинки должны находится в той же папке где и `data.json5` для данной колоды.
3. Для каждой новой колоды в её корневой папке должна быть создана специальная подпапка `rules/preview`, которая должна обладать следующим содержимым:
   ```
   ./Free Games
        ./<game-name>
            ./rules
                ./preview
                    preview.html → здесь необходимо создать html–страничку в которой сформировать красивое представление для игры (прояви фантазию: приложить html-рендеры для выбранных карт (3-4 карты достаточно), что-нибудь ещё...)
                    card-1-(face|back).html
                    card-2-(face|back).html
                    card-3-(face|back).html
                    card-4-(face|back).html
   ```
   * выбранные html-рендеры должны быть скопированы из папки `_autogenerated` соответствующей игры, которые получаются путём генерации через команду: `deck_gen.exe html --name <имя игры>`
   * preview.html должен зависеть только от файлов находящихся с ним в одной папке.
  
# Дополнительные указания
1. О результатах отпишись в `WiKi\result.md` в формате `было→стало(почему)` (очисти файл, если там есть какое-то содержимое перед новой записью).
2. если от меня требуются какие-то действия, то пиши их в `WiKi\note.md` (очисти файл, если там есть какое-то содержимое перед новой записью).
